# 広告カーテン for OBS

YouTube同時視聴配信で、広告が再生され始めたら**OBS側のソースを自動で非表示+ミュート**にし、
広告が終わったら自動復帰するChrome拡張機能です。

## コンセプト(重要)

**この拡張機能は広告をブロック・スキップ・非表示にしません。**
広告はブラウザ上で普通に完全再生されます。切り替わるのはOBS(=あなたの配信画面)の表示だけです。
「広告が流れるたびに慌てて手動でウィンドウを隠す」運用を自動化し、
広告素材が配信に映り込む事故を防ぎます。

## セットアップ

### 1. OBS側(OBS Studio 28以降)

1. OBSのメニュー「ツール」→「WebSocketサーバー設定」を開く
2. 「WebSocketサーバーを有効にする」にチェック
3. 「接続情報を表示」でポート(既定4455)とパスワードを確認

### 2. 拡張機能のインストール

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択

### 3. 拡張機能の設定

1. 拡張機能アイコン→「設定を開く」
2. OBSのポート・パスワードを入力
3. **OBSソース名**に、YouTubeを映しているソースの名前を正確に入力
   (例: ウィンドウキャプチャの「YouTube同時視聴」)。
   音声を別ソース(アプリケーション音声キャプチャ等)で取っている場合は
   「映像用, 音声用」のように**カンマ区切りで複数指定**できます
4. 「接続テスト」で接続を確認 →「保存」
5. ポップアップで「有効化」をON

## 機能

### 自動カーテン(基本機能)

YouTubeのタブで広告の再生が始まると、指定ソースを**全シーンで非表示**にします。
ソースを非表示にすればそのソースの音声も止まるため、音声ミキサーのミュート操作は行いません。
音声を別ソース(アプリケーション音声キャプチャ等)で取っている場合は、
そのソース名もカンマ区切りで指定してください(非表示になれば音も止まります)。
広告が終わると復帰ディレイ(既定300ms)の後、**元の表示状態**に戻します
(元から非表示にしていたシーンのソースは非表示のままです)。

### 動画終了後のカーテン(既定ON・設定で変更可)

動画が最後まで再生されたら自動でカーテンを閉じ、
**次の動画の再生が始まったら**自動で開きます。
同時視聴で次の動画を探す間の検索画面・おすすめ欄などが配信に載りません。

### 事前消化モード(オプション)

同時視聴を始める前に、対象動画のページでポップアップから「事前消化を開始」を押すと:

1. カーテンを閉じたまま、本編だけを**16倍速・ミュート**で走破します
2. 広告が来たら**等速に戻して普通に再生**します(スキップは自動で押しません。手動でどうぞ)
3. 最後まで走破したら先頭(0:00)に戻して停止し、カーテンを開きます

同一ページセッション内では消化済みの広告枠は再発火しにくいため、
その後の同時視聴では広告中断なしで再生できる**可能性が高まります**。

> **注意**: これはYouTubeの公開仕様ではなく経験則です。時間経過や仕様変更で
> 広告が再度出ることはありえます。その場合も基本機能の自動カーテンが働くので、
> 配信に広告が載ることはありません。

### フェイルセーフ(隠す側に倒す)

YouTubeの仕様変更などで広告検知が機能しなくなった場合、
「誤って広告が配信に載る」より「映像が消える」ほうがマシ、という方針で
**検知不能を検出したらカーテンを閉じます**。具体的には:

- 動画ページなのにプレイヤーを10秒以上見つけられない
- 動画ページを開いているのに監視信号が25秒以上途絶した

このときバッジに赤い表示が出ます。誤発動が多い場合は設定でOFFにできます。

## バッジの意味

| バッジ | 意味 |
|---|---|
| 赤「AD」 | カーテン中(広告検知・事前消化・フェイルセーフのいずれか) |
| 赤「!」 | カーテンが必要なのにOBSを操作できない(接続断)。**配信画面を確認してください** |
| 橙「!」 | 有効化中だがOBSに未接続(再接続を試行中) |

## トラブルシューティング

- **広告が来てもカーテンが閉じない**: ポップアップの「このタブ」表示を確認してください。
  「監視未動作」の場合はそのYouTubeタブを再読み込みしてください
  (拡張機能の更新・再読み込み時は開いているタブへ自動で再注入されますが、
  それより前から開いていた特殊な状態のタブでは手動リロードが必要なことがあります)
- **勝手にカーテンが閉じた**: ポップアップの「状態」にカーテンの理由が表示されます。
  「フェイルセーフ」と出ている場合は監視できていないYouTubeタブが残っています

## 既知の制約

- **グループ内のソースは指定できません**(obs-websocketの制約)。グループごと隠す場合はグループ名を指定してください
- YouTubeのDOM構造変更で広告検知が壊れる可能性があります。その場合はフェイルセーフによりカーテンは閉じる側に倒れます(更新をお待ちください)
- 検知からOBS反映まで100〜300ms程度かかるため、広告の冒頭が一瞬映る可能性はゼロではありません。気になる場合はOBS側で数百msの遅延フィルタを映像ソースに掛けると完全に隠せます
- パスワードはこの端末の拡張機能ストレージにのみ保存されます
