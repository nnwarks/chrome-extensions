# ストア掲載情報: 広告カーテン for OBS

## 基本情報

- 名前: 広告カーテン for OBS
- カテゴリ: ツール
- 言語: 日本語

## 短い説明(132字以内)

YouTube広告の再生中だけOBSのソースを自動で非表示にし、終わると自動復帰。同時視聴配信に広告を映さないための配信者向けツール。広告のブロックは行いません。

## 詳細説明

YouTube動画の同時視聴配信で、広告が再生され始めたら
OBSでYouTubeを映しているソースを自動で非表示にし、
広告が終わったら自動で元に戻す配信者向けツールです。

【重要: 広告をブロックしません】
本拡張機能は広告のブロック・スキップ・非表示を一切行いません。
広告はブラウザ上で通常どおり完全に再生されます。
切り替わるのはOBS(あなたの配信画面)の表示のみです。
「広告が流れるたびに慌てて手動でソースを隠す」運用を自動化し、
広告素材が配信に映り込むことを防ぎます。

【機能】
・広告再生の検知でOBSソースを自動非表示、終了で自動復帰(OBS 28以降のWebSocket機能を使用)
・動画が最後まで再生されたら自動非表示、次の動画の再生開始で復帰
 (次の動画を探す間の画面操作を配信に載せません)
・事前消化モード: 同時視聴前に本編のみを16倍速で走破し広告枠を先に消化
 (広告は等速で通常再生されます。スキップの自動操作は行いません)
・フェイルセーフ: 広告検知が機能しない状態を検出したら安全側(非表示)に倒します
・カーテン動作テスト、接続テスト、ソース名一覧表示などの診断機能

【セットアップ】
1. OBSの「ツール → WebSocketサーバー設定」でサーバーを有効化
2. 拡張機能の設定画面で接続情報とソース名を入力(接続テストで確認可能)
3. ポップアップで有効化

【通信について】
本拡張機能が接続するのは、あなたが設定画面で指定したOBSだけです
(初期設定は同一PC内のlocalhost)。
開発者や第三者のサーバーへの送信、ユーザーデータの収集は一切ありません。

【注意事項】
・本拡張機能はYouTube/Google/OBS Projectとは無関係の非公式ツールです
・YouTubeの仕様変更により検知が動作しなくなる場合があります
 (その場合も安全側=非表示に倒れる設計です)

## 審査フォームの回答案

- 単一用途の説明: YouTubeページ上の広告再生状態を検知し、ローカルPC内の
  OBS Studioに対してソースの表示/非表示を切り替える。配信画面の制御のみを
  行い、YouTubeの表示・再生・広告には干渉しない。
- storage 権限の理由: OBS接続設定(ポート・パスワード・ソース名等)の保存。
- scripting 権限の理由: 拡張機能のインストール/更新時に、既に開いている
  YouTubeタブへ監視スクリプトを注入するため(タブの再読み込みを不要にする)。
- ホスト権限(www.youtube.com)の理由: 広告再生状態(プレイヤーのクラス変化)を
  検知するコンテンツスクリプトの実行のため。
- リモートコード: 使用しない。
- 通信先: ユーザーが設定したOBSのみ(既定 ws://127.0.0.1)。開発者・第三者サーバーへの送信なし。
- データ収集: 一切なし(収集・送信ゼロを申告)。

## 審査対策メモ

- 説明文の冒頭近くに「広告をブロックしない」を明記済み。審査担当が
  アドブロッカーと誤認しないことが最重要
- スクリーンショットは「OBS画面(ソースが隠れた状態)+ポップアップ」など、
  OBS連携ツールであることが伝わる構図にする

## 必要アセット(手動作業)

- スクリーンショット1280x800を1枚以上:
  配信画面のビフォー/アフター(広告中にカーテンが閉じている様子)、設定画面など
