# コメントシーク for YouTube Live

YouTubeのライブ配信アーカイブの「チャットのリプレイ」で、各チャットメッセージに
**少し前へジャンプするボタン（⏪）** を追加するChrome拡張機能です。

「コメントに配信者がいい反応をした瞬間」をすぐ見返したいときに使います。
ボタンを押すと、そのコメントが投稿された時刻の数秒前（既定5秒・設定可）へ
動画の再生位置が移動して再生されます。

## 機能

- チャットリプレイの各コメント（通常メッセージ・スーパーチャット・メンバーシップ等）に
  ジャンプボタンを注入します。
- ボタンを押すと、そのコメントの時刻の「指定秒数だけ手前」から再生します。
- 何秒前へ飛ぶかは設定画面（0〜60秒、既定5秒）で変更できます。

## インストール手順（デベロッパーモードで読み込み）

1. Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
4. このフォルダ（`comment-seek-for-ytlive`）を選択します。
5. 拡張機能一覧に「コメントシーク for YouTube Live」が表示されれば完了です。

## 設定

拡張機能一覧の本拡張の「詳細」→「拡張機能のオプション」、または
ツールバーアイコンのメニューから設定画面を開き、
「コメント時刻の何秒前へ飛ぶか」を変更できます。変更は即座に反映されます。

## 使い方

1. YouTubeで、チャットのリプレイがあるライブ配信アーカイブを開きます。
2. 右側のチャットリプレイ欄の各コメントに ⏪ ボタンが表示されます。
3. 見返したいコメントの ⏪ を押すと、その少し前から再生されます。

## 動作条件・注意事項

- **「チャットのリプレイ」があるアーカイブでのみ動作します。**
  ライブ配信中や、チャットリプレイが無い動画では動作しません。
- YouTubeのページ構造（DOM）は予告なく変更されることがあります。
  その場合、ボタンが表示されない・ジャンプできないなど、
  拡張機能が正しく動作しなくなる可能性があります。
- チャット欄の時刻表示（例: `1:23:45`）を基準にジャンプします。

## 技術メモ

- チャットリプレイは watchページ内の iframe
  （`https://www.youtube.com/live_chat_replay?...`）で動作します。
- iframe内のcontent script（`chat.js`）がボタンを注入し、クリック時に
  `window.parent.postMessage` でトップフレームへ移動先の秒数を送ります。
- トップフレームのcontent script（`player.js`）がそれを受信し、
  `video.currentTime` を変更して再生します。

## ファイル構成

- `manifest.json` … 拡張機能の定義（Manifest V3）
- `chat.js` … チャットリプレイのiframe側。ボタン注入と時刻→秒変換、親フレームへの送信。
- `player.js` … watchページのトップフレーム側。秒数を受信して再生位置を移動。
- `chat.css` … 注入するボタンの見た目。
- `options.html` / `options.js` … 設定画面（何秒前へ飛ぶか）。
- `README.md` … 本ファイル。
